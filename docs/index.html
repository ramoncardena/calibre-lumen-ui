Two files. Zero dependencies.

No containers to babysit, no database to migrate, no node_modules. Lumen is a single-page UI and a small Python proxy that runs on the standard library alone. If you have Python 3, you can run it.

server.py
Serves the UI and proxies the Calibre API — reads, writes, covers, downloads, metadata search, AI.
index.html
The entire interface. One file you can read, theme, and hack on.
⌕

Search like Calibre

Full Calibre query syntax in a live search box, with a tag-browser sidebar: authors, series, tags, ratings, languages, and your custom columns.

✓

Reading status

Read, in progress, or on the pile — one tap to mark, badges on covers, filters with live counts. Backed by ordinary Calibre yes/no columns.

✎

Edit metadata

The full Calibre field set in a clean dialog: titles and sorts, series, identifiers, dates, languages, comments, covers, and click-to-rate stars.

⇣

Fetch metadata

Pull title, description, identifiers, and covers from Google Books and Open Library. Inspect every candidate before applying it.

⇩

Download anywhere

Every format of every book, one click away, from any device on your network — phone, tablet, or the browser on your e-reader.

◷

Stays in sync

Lumen writes through the Calibre Content Server API. The desktop app, OPDS feeds, and your reader always see the same library.

Ask the book itself.

Every book gets an AI button with three focused actions — no chat window to babysit, just answers. Bring your own key for OpenAI, Anthropic, or xAI.

📚

Find similar books

Six to eight recommendations shaped by the book's genre, themes, and tone — one line each, with the reason it fits. No repeats from the same series, no padding.

The Long Quiet — H. Sato: first contact told through linguists, same slow-burn dread. Driftglass Station — P. Onu: isolated crew, unreliable signals, tighter thriller pacing. A Theory of Ghosts — R. Calloway: the same big ideas, aimed at grief instead of fear. anthropic · claude-sonnet-4-6
📝

Spoiler-light summary

Two short paragraphs — the premise and what makes it notable — then the main themes. Built to help you pick your next read without ruining it.

A radio array on a dying station picks up a pattern that shouldn't exist, and the one engineer who notices can't make anyone believe her. What starts as a procedural about signal noise becomes a story about who gets listened to. Themes Isolation · institutional doubt · the cost of being right openai · gpt-4o-mini
💬

Contextual questions

Ask anything about the book. Tick "Send the book text" and Lumen extracts your EPUB on your server and hands the model the actual pages — so plot questions get answers from the text, not from guesswork. Spoiler answers warn you first.

Does this one stand alone, or do I need book one first? It stands alone. Book one is recapped in two early chapters — the only thing you'd miss is recognizing a returning minor character. xai · grok-4 · book text included

Keys live in a .env on your server and work from every device; any browser can override with its own. Book metadata — and the text, only when you tick the box — goes to the provider you chose. Nothing leaves your server until you click.

Running in two minutes.

Point it at your Calibre Content Server and open a browser.

# grab the two files
$ git clone https://github.com/ramoncardena/calibre-lumen-ui.git
$ cd calibre-lumen-ui
# point it at your content server
$ python3 server.py --calibre http://127.0.0.1:8081
# open http://your-host:8090 — that's it

Editing and AI are optional extras — a trusted-IP setting for writes, a .env for keys. The README covers both.
